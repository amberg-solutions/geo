Vom Python-Backend zur interaktiven Karte

Dieses Beispielprojekt lädt zyklisch Daten vom Datenportal Graubünden zu Toursimusdestinationen und speichert diese in meiner Postgres Datenbank. Beim Besuch der Seite, werden die Daten asynchron von Javascript via eigener API aus Postgres abgerufen und im Frontend gerendert.

Python PostgreSQL Flask Folium Leaflet JavaScript
  1. 01

    Anfrage

    Der Browser lädt die Oberfläche und ruft anschließend den Endpunkt /get_map auf.

  2. 02

    Verarbeitung

    Das Backend bereitet die Daten aus dem Backend bzw. via API aus Postgres auf.

  3. 03

    Darstellung

    Das Frontend übernimmt das Ergebnis als JSON und rendert die fertige Karte in einem iframe.
